# Депость — казик для своих

Кейсы с мемами, инвентарь, деп-батл между друзьями и рулетка. Монеты ненастоящие, вывести их нельзя.

## Что лежит в папке

```
index.html            — вся игра
memes/manifest.json   — названия и редкость мемов
memes/                — сюда кидаешь картинки с мемами
```

## 1. Выложить на GitHub

1. Зарегистрируйся на github.com.
2. Нажми **New repository**, назови его, например, `depalka` и выбери **Public**.
3. Нажми **uploading an existing file** и перетащи туда `index.html` и папку `memes`.
4. Закинь в папку `memes` свои картинки с мемами. Переименовывать их не обязательно: игра узнаёт скриншоты по времени в названии (табличка ниже). Новые мемы без записи в manifest тоже подхватятся, получат название по имени файла и случайную редкость.

## 2. Включить сайт

**Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.**
Через минуту-две игра откроется по адресу `https://b0dr0dev.github.io/depalka/`.

## 3. Подключить Telegram-бота

1. В Telegram открой **@BotFather** и отправь `/newbot`. Придумай имя, и он выдаст бота.
2. Отправь `/mybots` → выбери бота → **Bot Settings → Menu Button**.
3. Вставь ссылку на сайт из шага 2 и назови кнопку, например «Играть».

Теперь у бота внизу появится кнопка, и игра откроется прямо в Telegram. При входе игра спрашивает имя (в Telegram оно уже подставлено) и превращает его в «-ость»: Рома → Ромость, Артемий → Артемость.

## Новые кейсы со своими мемами

Чтобы мем выпадал не в кейсах Меллстроя, а в отдельном кейсе, добавь ему в `manifest.json` поле `"set"`. Например, `"set": "yt"` — кейс «Ютуберы».

## Важно

- Пока прогресс (балансы, инвентарь) хранится на телефоне каждого игрока. Чтобы у всех был общий батл и общий LIVE, нужен сервер. Это следующий шаг.
- Репозиторий публичный, поэтому картинки в нём видит кто угодно.
