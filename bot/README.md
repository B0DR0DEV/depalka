# Бот Депости

Бот продаёт донат и сам выдаёт промокоды. Деньги ты принимаешь как обычно (перевод), бот только присылает тебе заявку, и после твоего «Выдать» отправляет другу код и ссылку активации.

## Запуск на Windows

1. Установи Python с python.org. В установщике поставь галочку **Add python.exe to PATH**.
2. Создай бота: в Telegram открой **@BotFather** → `/newbot` → придумай имя → скопируй токен.
3. Скачай из репозитория папку `bot` (нужен только `bot.py`) и положи **рядом с ним файл `codes.txt`**, который тебе прислал Claude. На GitHub его не загружай.
4. Открой папку с `bot.py`, в адресной строке проводника напиши `cmd` и нажми Enter. В чёрном окне напиши `python bot.py`.
5. Бот попросит токен — вставь его и нажми Enter.
6. В Telegram напиши своему боту `/iamadmin`. Теперь заявки будут приходить тебе.

Бот работает, пока открыто это окно и включён комп. Если Telegram у тебя работает только через VPN, VPN на компе тоже должен быть включён.

## Настройка

После первого запуска рядом появится `config.json`:
- `pay_text` — что написать покупателю про оплату (например, куда переводить);
- `channel_url` — ссылка на твой канал с паками (появится кнопка «📦 Паки в канале»);
- `products` — названия и цены.

Поменял — перезапусти бота (Ctrl+C и снова `python bot.py`).

## Команды

- `/start` — меню с донатом;
- `/iamadmin` — стать админом (срабатывает только один раз);
- `/left` — сколько кодов осталось (только для админа);
- `/myid` — показать свой id.

## Запуск на Orange Pi (Armbian)

Плата работает круглосуточно, поэтому бот не зависит от компа.

1. Скопируй на плату папку `bot` (`bot.py` и `install-orangepi.sh`) и положи туда `codes.txt`. Удобно через флешку или `scp`.
2. Открой на плате терминал, перейди в эту папку и запусти:
   ```
   bash install-orangepi.sh
   ```
3. Скрипт спросит токен бота и прокси, если Telegram открывается только через VPN (см. ниже).
4. Напиши боту `/iamadmin`.

Бот сам запускается при включении платы и перезапускается при сбоях. Логи: `journalctl -u depost-bot -f`.

### Если Telegram из России не открывается

Боту нужен доступ к `api.telegram.org`. Поставь на плату VPN-клиент (например, xray или sing-box) с включённым **HTTP-прокси** на `127.0.0.1` и укажи его адрес при установке, например `http://127.0.0.1:10809`. Тогда через VPN пойдёт только бот, остальная сеть платы останется как была. Адрес прокси можно поменять потом в `/opt/depost-bot/config.json` (поле `proxy`) и перезапустить бота.

VPN-ключ никому не отправляй: это как пароль, по нему кто угодно сможет пользоваться твоим VPN.
