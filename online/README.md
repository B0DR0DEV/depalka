# Онлайн Депости на Supabase

## 1. Создай проект
1. Зайди на supabase.com → **Start your project** → войди через **GitHub** (тот же аккаунт B0DR0DEV).
2. **New project**: имя `depost`, придумай и сохрани пароль базы, регион **Central EU (Frankfurt)** — он ближе всего к России.
3. Подожди 1–2 минуты, пока проект создаётся.

## 2. Проверь, открывается ли Supabase без VPN
На телефоне **без VPN** открой в браузере `https://ТВОЙ-ПРОЕКТ.supabase.co/rest/v1/` (адрес проекта есть на главной странице проекта).
- Видишь текст вроде `{"message":"No API key found in request"...}` — всё работает.
- Страница не грузится — Supabase у вас заблокирован, онлайн через него без VPN не заработает.

Лучше проверить на нескольких телефонах и у разных операторов (мобильный интернет и Wi-Fi).

## 3. Включи вход без регистрации
**Authentication** → **Sign In / Providers** → включи **Allow anonymous sign-ins** → **Save**. Так игрокам не нужно регистрироваться, игра сама создаёт им аккаунт.

## 4. Создай таблицы и функции
**SQL Editor** → **New query** → вставь целиком файл `depost-install.sql`, который прислал Claude → **Run**. Должно написать «Success».

В этом файле вся экономика (кейсы, апгрейд, краш, контракт, рулетка, батлы, трейды, сезоны, задания) и хэши промокодов. В репозитории лежит такой же `online/install.sql`, только **без промокодов** — промокоды в GitHub не выкладываются.

Если добавил новый пак или поменял мемы: запусти `python online/build_catalog.py` и выполни в SQL Editor `online/catalog.sql` (его можно запускать сколько угодно раз, прогресс игроков не трогает).

## Depost+ — серверная синхронизация

После установки основной схемы выполни в Supabase SQL Editor файл `online/depost_plus.sql` из репозитория.

Он создаёт отдельные таблицы для титула профиля, избранного, истории и дружбы. Таблицы закрыты RLS и не доступны для прямой записи из браузера; изменения выполняются только через `api_plus_*` RPC-функции с проверкой текущего `auth.uid()`.

- Избранное и титул сохраняются на сервере.
- Достижения и недельный прогресс вычисляются сервером по сохранённым данным.
- Заявки в друзья, принятие, отклонение и удаление выполняются сервером.
- Запросы в друзья ограничены по частоте.
- В клиентском коде нет возможности напрямую начислять XP или выставлять достижения.

## 5. Пришли Claude два значения
**Project Settings** → **API** (или **Data API** / **API Keys**):
- **Project URL** — вида `https://abcd1234.supabase.co`;
- **anon public** ключ (или **publishable key**, начинается с `sb_publishable_`).

Эти два значения не секретные: они и так будут видны в коде сайта, а данные защищены правилами базы.
**Никогда не отправляй `service_role` / `secret` ключ** — это полный доступ к базе.

## 6. Что включится
- 🔒 **Честная экономика** — баланс и инвентарь хранятся на сервере, все выпадения и выигрыши считает сервер. Подправить монеты на телефоне нельзя.
- 🏆 **Таблица лидеров с сезонами** — сезон длится неделю. Очки сезона — сколько монет игрок выиграл за неделю. Топ-1 получает уникальную корону «Король сезона N».
- 🔴 **Общий LIVE** — лента сверху показывает дропы всех игроков.
- 🌐 **Батлы с друзьями** — ставки замораживаются на сервере, победителя выбирает сервер. В комнате можно кидать реакции.
- 🤝 **Обмены** — в таблице лидеров нажми на игрока → «Предложить обмен».
- 📅 **Задания дня и серия входов** — 3 задания в день, бонус за каждый день подряд (до 700 монет).
- 📢 **Плюшки за подписку на канал** — 5 000 монет, мем «Подписчик», кейс «Для своих» и +50% к бонусу за вход. Подписку проверяет бот (настройка в `bot/CLOUDFLARE.md`, шаги 9–10).
- 💬 **Чат** — общий чат всех игроков, кнопка 💬 справа внизу. Не чаще раза в 2 секунды, до 300 символов.
- 📅 **Ежедневный кейс** — бесплатно раз в день (по Москве), внутри скины CS2, легенда в 2% случаев.
- 🌈 **«Шейх»** — кейс за 1,9 млн, топ «Karambit | Радужный бриллиант» за 25 млн (шанс 0,04%).
- 🛠 **Админка** — появляется во вкладке «Ещё» после ввода админского кода в поле промокода (код в GitHub не лежит). Деньги и предметы игрокам, «админ абьюз» для всех: денежный дождь, раздача, удача ×N, скидка на кейсы.
- 🏖 **Песочница** — старый режим без сервера: свои монеты, можно вдвоём на одном телефоне, в таблицу не идёт.

## Depost+ V2 — социальная часть и оформление

После `online/depost_plus.sql` один раз выполни `online/depost_plus_v2.sql` в Supabase SQL Editor.

V2 добавляет:
- ленту активности друзей;
- публичную витрину профиля с описанием, темой, рамкой и настройкой приватности;
- личные сообщения только между друзьями, с лимитом длины и частоты;
- альбомы коллекций (до 10 альбомов, до 20 карточек в каждом);
- статистику и временную шкалу профиля;
- недельные цели и скрытые достижения за профиль, коллекции и социальные действия;
- блокировки и отправку жалоб;
- серверные проверки доступа к профилям и сообщениям.

**Порядок миграций:** `online/install.sql` (если ещё не установлен) → `online/depost_plus.sql` → `online/depost_plus_v2.sql`. Не запускай основной `install.sql` повторно поверх уже работающей базы.
